# Listening tests

Real-voice listening is pending until a verified model adapter and owner voice
profile exist. Do not treat the synthetic Phase 0 tone as a listening sample.

When the real pipeline is available, listen to:

1. A cleaned reference compared with the original: check noise, clipping, and
   whether cleanup changes the voice unnaturally.
2. A short neutral Bangla test line: check pronunciation, similarity, and pace.
3. The same paragraph in Documentary and Dark Mystery: check style difference
   while preserving identity.
4. A longer render at sentence joins: listen for clicks, gaps, or volume jumps.
5. Music mix and SRT: check speech clarity and subtitle timing.

Record model/version, settings, and notes for each listening session. Owner
feedback is required before claiming voice quality acceptance.
